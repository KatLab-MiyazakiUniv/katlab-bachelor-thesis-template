\chapter{考察}\label{cha:Discussion}

本章では、実験結果に基づき、作成したプロンプトの実務的な意義と限界について考察する。

\section{実務への示唆}
本実験の結果から、以下の実務への示唆が得られる：

\begin{itemize}
    \item \textbf{テンプレートプロンプトの活用}: システム仕様書の章立て作成において、テンプレートプロンプトを活用することで、経験の浅い技術者でも高品質な章立てを作成できる。
    
    \item \textbf{LLMの適切な活用}: LLMを単独で使用するのではなく、明確な指示（テンプレートプロンプト）と組み合わせることで、より高品質な成果物を得られる。
    
    \item \textbf{品質の標準化}: テンプレートプロンプトにより、章立ての品質を標準化し、プロジェクト間での一貫性を確保できる。
    
    \item \textbf{教育ツールとしての活用}: テンプレートプロンプトは、新人技術者がシステム仕様書の構造を学ぶための教育ツールとしても活用できる。
\end{itemize}

これは、テンプレートプロンプトが提供する「ベース章立て」が一般的な構造を示すものであり、特定のシステムに特化した詳細な項目までは網羅できないためと考えられる。
今後、システムの種類や規模に応じたテンプレートプロンプトのバリエーションを用意することで、この課題を改善できる可能性がある。

% \section{章の構成}

論文は複数の章で構成される。各章は \verb|\chapter{}| コマンドで定義する。

% \subsection{章番号の自動付与}

LaTeX では章番号が自動的に付与される。
例えば、本章は第\ref{cha:Evaluation}章である。

% \subsection{章のラベル付け}

各章には \verb|\label{}| を付けることで、他の箇所から参照できる。
これにより、章番号が変更されても参照が自動的に更新される。

% \section{セクションの構成}

各章は複数のセクションで構成される。

% \subsection{セクションの階層}

LaTeX では以下の階層構造が使用できる：

\begin{enumerate}
  \item \verb|\chapter{}|: 章 (1, 2, 3, ...)
  \item \verb|\section{}|: 節 (1.1, 1.2, 1.3, ...)
  % \item \verb|\subsection{}|: 小節 (1.1.1, 1.1.2, 1.1.3, ...)
  \item \verb|\subsubsection{}|: 小小節 (1.1.1.1, 1.1.1.2, 1.1.1.3, ...)
\end{enumerate}

% \subsection{適切な階層の選択}

論文の構成を考える際は、以下の点に注意する：

\begin{itemize}
  \item 階層が深くなりすぎないようにする（通常は subsection まで）
  \item 各セクションには適切な量の内容を含める
  \item セクションの粒度を統一する
\end{itemize}

% \section{論文の一般的な構成}

片山徹郎研究室で主に使われてきた、修士論文の一般的な構成は以下の通りである：

\begin{enumerate}
  \item はじめに
  \item 研究の準備（使用ツール、ライブラリの紹介）
  \item 機能
  \item 実装
  \item 適用例
  \item 考察
  \item おわりに（まとめと今後の課題）
\end{enumerate}

この構成が全てではなく、研究内容に合わせて適宜変更されることが多い。
例えば、卒業論文で開発したツールの拡張を行う場合は、拡張した箇所の説明を追加することが多い。
詳細な構成などは、片山研の \verb|graduate| フォルダにある論文を参考にすると良い。
